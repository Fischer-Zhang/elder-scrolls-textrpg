# 流亡者 (tesrpg)

一個上古卷軸 (The Elder Scrolls) 世界觀的**技能驅動沙盒**文字角色扮演遊戲,跑在終端機(亦有瀏覽器 Web 版)。
做什麼、就練什麼 (learn-by-doing):你揮劍就練劍術、放火球就練毀滅魔法、撬鎖就練安全。
單一英雄,跨七省探索鑽地城、戰士/法師/盜賊/刺客多系玩法,直到陣亡或隱退,結算一生傳奇。

完整設計見 [DESIGN.md](DESIGN.md);接手開發的詳細現況地圖見 [handoff.md](handoff.md)。

## 需求
- Python 3.11+
- [`rich`](https://github.com/Textualize/rich)(終端 UI)

Debian/Ubuntu 系可用系統套件:`sudo apt install python3-rich`,或 `pip install rich`。

## 執行

```bash
python3 -m tesrpg            # 終端機版(或 python3 -m tesrpg.main)
python3 -m tesrpg.web        # Web 版 → 瀏覽器開 http://127.0.0.1:8080
```

存檔在 `~/.tesrpg/save.json`(repo 外)。

## 測試

```bash
python3 tests/run_all.py     # 不需要 pytest;43 個測試模組,目前全綠
```

## 目前進度

**M0–M16 全部完成,並在其上疊了二十餘輪內容/系統強化、全部上 GitHub。** 以下依系統分類列出現況(里程碑歷程詳見 DESIGN.md / handoff.md):

### 角色與成長
- 角色創建:**10 種族 × 13 出生星座 × 8 預設職業 / 自訂**;八屬性 + **23 技能** + 衍生數值(生命/魔力/體力/負重)
- **learn-by-doing 技能引擎** + 混合 Skyrim 式升級(各技能餵「等級 XP 池」→ 升級給三選一資源 + 屬性點自由分配,消除 min-max 與耐力時機陷阱)
- **技能里程碑(Skill Mastery v2)**:全 23 技能各 ≥1 節點,達門檻**二選一**永久銘刻 + 持久 fortify 加成層(守反 min-max)
- **開局背景**(Live Another Life 式,14 種開局只給「處境」不給數值)+ **種子重玩性**(同種子+同選擇=同世界同命運)
- **冒險 / 傳奇(永久死亡)兩種模式** + 死亡或隱退的**一生傳奇總結**評分與稱號

### 戰鬥與魔法
- 回合制**多敵 + 團隊戰鬥**(召喚物/旅店傭兵同伴並肩作戰、可指定目標)
- **八大魔法學派** + **AoE 法術**;**元素抗性/弱點**、狀態效果(DoT/麻痺/再生)、**出生星座每日之力**
- **煉金毒藥 + 武器塗毒**;**潛行系戰鬥化**:偷襲先攻、暗殺殘響(踉蹌/撕裂)、雙持匕首、隱遁再襲、戰前偵查
- 護甲分重/輕、格擋、武器流派(匕首/弓潛襲、鈍器破甲、速度影響命中/耗體)

### 世界與探索
- **七省 36 地點 / 17 城**(賽羅迪爾·天際·晨風·黑沼澤閉合世界大環 + 漢默法爾·高岩·瓦倫森林),旅行耗時、晝夜、危險度
- **生態遭遇**(biome 加權:雪原/火山/沼澤/腹地/沙漠… 一出城就知在哪省)、**省份風味事件**、**具名地標**首次發現、各城**考據統治者**
- 地城多房間 + 上鎖寶箱 + 強化首領與寶藏;終局 solo BOSS(魔人領主/上古巨龍/吸血鬼貴族…)

### 製作與裝備
- **鍛造**(金屬四階 elven/dwarven/glass/ebony + **頂級魔族/龍鱗/龍祭司**)、**裁縫**、**淬鍊強化**;**附魔**(武器/護甲/飾品)
- **套裝加成**(同材質四件)、武器流派、飾品槽、法杖、法袍;**頂級稀有素材鍛造**(終局 boss 掉素材 → 高鍛造)+ **具名神器**
- 裝備耐久 + 鐵匠修理 / 修理鎚自修

### 公會、任務與政治
- **六大公會**:戰士/法師/盜賊(技能門檻 + 階級福利 + 對立排他 + 分支壓軸)、**黑暗兄弟會**(血債招募 + 合約晉升 + 夜母祝福)、**神話黎明**、**九神騎士團**
- **多階段任務引擎**(四類目標自動結算 + 敘事分支);告示板/NPC 委託;**犯罪賞金 + 衛兵盤查 + 謀殺**
- **吸血鬼化**(力量↔詛咒天平:陽光灼傷/社交封鎖/進食/解咒任務)
- **領主政治 / 城戰**:謁見領主 → 委託功勳 → **武士冊封**;**圍城方略 + 強攻破城 + 佔領收稅 + 招兵買馬**;**陣營動態大事件**(城邦易幟、四大義)
