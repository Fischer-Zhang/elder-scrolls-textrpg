# 流亡者 (tesrpg)

一個上古卷軸 (The Elder Scrolls) 世界觀的**技能驅動沙盒**文字角色扮演遊戲,跑在終端機。
做什麼、就練什麼 (learn-by-doing):你揮劍就練劍術、放火球就練毀滅魔法。
完整設計見 [DESIGN.md](DESIGN.md)。

## 需求
- Python 3.11+
- [`rich`](https://github.com/Textualize/rich)(終端 UI)

Debian/Ubuntu 系可用系統套件:`sudo apt install python3-rich`,或 `pip install rich`。

## 執行

```bash
python3 -m tesrpg
# 或
python3 -m tesrpg.main
```

**M8 — 戰鬥戰術縱深**
- ✅ **元素抗性與弱點**:種族抗性(暗精靈抗火、布萊頓抗魔…)與怪物抗性進入傷害計算 —— 對火魔人就別丟火、改用冰
- ✅ **狀態效果**:中毒/燃燒/凍傷持續傷害、麻痺、再生(複用 `active_effects` 逐回合結算,吃抗性)
- ✅ **出生星座招牌能力**(每日一次):領主再生、瑪拉祝福(治療+淨化)、戀人麻痺、蛇之詛咒、陰影遁形、塔之鑰(必開鎖)、巨魔像吸收魔法
- ✅ 怪物元素攻擊與中毒觸發;武器附魔/法術元素皆受抗性影響

**M9 — 煉金毒藥與武器塗毒**
- ✅ 煉金分流:兩種材料共通的**有害效果**(毒傷/麻痺)→ 調成毒藥(否則為恢復藥水)
- ✅ **武器塗毒**:把毒藥抹上武器,接下來數次命中對敵人施加中毒/麻痺(吃毒素抗性、跨存檔保留)
- ✅ 潛行/煉金流派的戰術回報(對耐久敵人顯著、對免疫毒素的亡者無效)

**M10 — 公會精英階任務線**
