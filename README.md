# 流亡者 (tesrpg)

一個上古卷軸 (The Elder Scrolls) 世界觀的**文字 RPG**:你是一名抵達 Tamriel 的無名冒險者,
**做什麼、就練什麼**——揮劍練劍術、放火球練毀滅、撬鎖練安全。沒有主線逼你走,
**你的技能成長軌跡就是你的故事**,直到陣亡或隱退,結算一生傳奇。

## 安裝與執行

需求:**Python 3.11+** 與 [`rich`](https://github.com/Textualize/rich)(後端用來把畫面渲成 HTML)。
Debian/Ubuntu:`sudo apt install python3-rich`,或 `pip install rich`。

本遊戲為**瀏覽器 Web 版**(純 stdlib 本機伺服器,零額外相依):

```bash
python3 -m tesrpg.web      # 啟動後用瀏覽器開 http://127.0.0.1:8080
```

存檔在 `~/.tesrpg/save.json`。

## 怎麼玩

### 1. 創一個角色
依序選:**姓名 → 性別 → 種族 → 出生星座 → 職業**,再挑一個**開局背景**(逃犯、傭兵、法師學徒、
沒落貴族、夜之裔…只給你「處境」,不給數值)。可輸入一個**種子**——同種子 + 同選擇 = 同一個世界同一段命運。
- **種族**決定屬性傾向與天賦(亞龍人抗病、凱季特夜視、布萊頓抗魔…)
- **星座**給被動或每日一次的能力;**職業**的主修技能會引導你的 build(升級加速)
- 死亡規則開局選:**冒險模式**(死亡可讀檔)或**傳奇模式**(roguelike 永久死亡)

### 2. 核心循環:做什麼,就練什麼
你在一個地點選一個**行動**,時間隨之推進(以小時計,休息/旅行可跨日),沿途觸發隨機奇遇與遭遇。
**每次使用技能就會練到它**;技能升點累積會讓你升級,升級時自由分配屬性點(5 點)並回滿三圍 —— 生命/魔力/體力由你投資的屬性(耐力/智力等)直接決定。

主選單依情境分區顯示:
- **冒險**:探索狩獵(城郊野外)、深入地城、旅行、看世界地圖
- **城區**:市集區(商店買賣 / **鍛造工坊** / 淬鍊強化)、公會區(各公會分部)、廣場(旅店過夜 / **訓練師**付錢練技能 / 告示板接委託 / 與人攀談)、領主區(謁見領主)
- **製作**:施法增益、煉金調藥/煉毒、武器塗毒、附魔
- **人物**:升級、任務日誌、背包、練習技能、原地休息、查看角色卡
- **系統**:存檔、隱退(主動結算一生傳奇)

### 3. 戰鬥
回合制,依速度決定先後。每回合可**攻擊 / 施法 / 格擋 / 用道具 / 逃跑**(潛行夠高還能**隱遁再襲**)。
- **偷襲先機**:潛行接近成功就能開場暴擊;匕首/弓更致命
- 注意**元素**:對火焰魔人別丟火、改用冰;武器塗毒對耐久敵人很有效
- 群戰很危險——找**同伴/傭兵**並肩、或當法師用範圍法術清場

### 4. 成長與闖蕩
- **加入公會**(戰士/法師/盜賊/黑暗兄弟會/神話黎明/九神騎士團):達技能門檻 + 完成晉升任務往上爬,直到登頂
- **技能里程碑**:某技能練到 50/75/100 會跳出**二選一**,永久銘刻一條精通(自動套用)
- **犯罪有代價**:行竊/殺人會累積賞金,帶賞金進城會被衛兵盤查(繳清/坐牢/拒捕/說服)
- **頂級裝備靠終局**:最強的魔族/龍鱗/龍祭司套裝與武器,要打**終局首領**取得稀有素材、再以高鍛造打造

### 上手提示
- 先在低危險度的城郊**探索狩獵**練技能、攢錢、買藥水,再往險地走
- 撬鎖要帶**開鎖器**(失敗會折斷);訓練師可付錢補練冷門技能
- 旅行與休息有風險遭遇,血/魔/體力低就先回城旅店或原地休息
- 死亡或隱退都會結算**一生傳奇總結**(走過的地方、最高技能、公會階級、擊殺、聲望 → 分數與稱號),想刷高分就活久一點、爬得高一點

## 測試

```bash
python3 tests/run_all.py       # 純 Python 單元/流程測試;模組數見輸出結尾
python3 tests/browser_ui.py    # Chromium 桌面 UI 回歸
bash check.sh                  # 兩套測試皆跑;提交前標準入口
```

瀏覽器回歸需要開發依賴與 Chromium。首次設定:

```bash
python3 -m pip install -e '.[dev]'
python3 -m playwright install --with-deps chromium
```

遊戲執行環境仍只有 `rich`；Playwright 僅供開發測試使用。
